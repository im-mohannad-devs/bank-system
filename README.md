# Bank Management System

## Description
This is a simple Bank Management System built with Python.

The system allows users to create bank accounts, log in using their account ID, and perform basic banking operations such as checking balance, depositing money, and withdrawing money.

The project focuses on applying core programming concepts such as functions, classes, dictionaries, loops, conditional statements, input validation, and error handling.

---

## Features
- Create a new bank account
- Generate a unique account ID for each user
- Log in using account ID
- Check account balance
- Deposit money
- Withdraw money
- Validate user input
- Prevent negative balances
- Simple menu-based interface

---

## Technologies Used
- Python 3
